# DiffData - CSV Sammenligningsværktøj

## Versioner

### v4.py — Stabil version
Den oprindelige og stabile version af værktøjet. Sammenligner to CSV-filer (legacy vs. target) og genererer en detaljeret rapport over forskelle.

**Funktioner:**
- Sammenligning af to CSV-filer på celle-niveau
- Automatisk detektering af CSV-separator
- Numeriske kolonne-summer for begge filer
- Primærnøgle-baseret rækkesammenligning
- Generering af tekstrapport
- Eksport af resultater til `sammenlign.xlsx`
- Tkinter GUI

### v5.py — Work in progress
En videreudvikling af v4.py. Denne version er under aktiv udvikling og vil tilføje database-funktionalitet.

> **OBS:** v5.py er ikke stabil og bør ikke bruges i produktion.
